# Figma → Frontend TaskSpec

Ты компилируешь Figma-макеты во фронтенд TaskSpec'ы для neurodeck.

## Шаг 1 — Прочитать макет

Используй Figma REST API. `FIGMA_TOKEN` из переменных окружения.

```bash
# Метаданные файла
curl -s -H "X-Figma-Token: $FIGMA_TOKEN" \
  "https://api.figma.com/v1/files/<FILE_KEY>?depth=4"

# Или конкретный фрейм
curl -s -H "X-Figma-Token: $FIGMA_TOKEN" \
  "https://api.figma.com/v1/files/<FILE_KEY>/nodes?ids=<NODE_ID>"
```

Извлеки `FILE_KEY` из URL: `figma.com/file/<KEY>/...` или `figma.com/design/<KEY>/...`.

## Шаг 2 — Обойти структуру

- Найди все FRAME/COMPONENT/COMPONENT_SET/SECTION верхнего уровня
- Для каждого контейнера: имя, размер, тип, количество дочерних элементов
- TEXT-ноды: содержимое, размер шрифта, жирность, цвет
- RECTANGLE/ELLIPSE: размер, цвет заливки, радиус скругления
- INSTANCE: имя мастер-компонента, варианты
- Дизайн-токены (из Figma Styles): цвета, типографика, эффекты

## Шаг 3 — Сгенерировать ТЗ

Структура выходного ТЗ:
```
# Макет Figma: <имя файла>
Файл: `<FILE_KEY>`
Фреймворк: react | vue | html

## Структура макета
<рекурсивное дерево компонентов с размерами, цветами, текстами>

## Фреймы (контейнеры)
<список top-level фреймов>

## Дизайн-токены
<цвета, типографика, эффекты из Figma Styles>

## Задача: реализация макета
Сверстать макет из Figma. <специфичные для фреймворка инструкции>

### Требования:
1. Разбить на переиспользуемые компоненты (атомы/молекулы/организмы)
2. Адаптивный дизайн (mobile-first, брейкпоинты: 375/768/1024/1280)
3. CSS-переменные для цветов и типографики из макета
4. Интерактивные элементы: ховеры, фокусы, переходы
5. Доступность: aria-атрибуты, контраст, keyboard navigation
6. Загрузка данных через props/hooks (мок-данные для начала)
7. i18n: все строки через словарь (русский + английский)

### На выходе:
- Компоненты в `resources/js/Components/<FeatureName>/`
- Сторибук для каждого компонента (минимум 2 варианта)
- Тесты рендеринга (Vitest/Jest)
- Файл со стилевыми токенами

Формат коммитов: `#NNNNN feat(frontend): <описание>`
```

## Шаг 4 — Сохранить результат

Сохрани готовый TaskSpec в `harness/queue/figma-<KEY>.json` и `.prompt.md`.

## Примечания
- Если нет FIGMA_TOKEN — скажи что нужен токен
- Если макет слишком большой — обрежь до первых 3 страниц/8000 символов
- Без Figma-маппинга в `config/projects.json5` target репо не определяется автоматически — укажи это
