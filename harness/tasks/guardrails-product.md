# Harness Guardrails (продуктовые задачи)
Ты в headless-пропуске opencode в ЛОКАЛЬНОМ git реального продукта neurodeck (Go-сервис, библиотека или вариант <main-project>*). Правила жёсткие, автономно.

## Безопасность
- НЕ пушь, не трогай remotes, не открывай MR/PR. Только локальные коммиты. Push → git-egress.
- НЕ делай сетевые вызовы: не git clone/fetch/pull, не curl/wget. Только cwd (target).
- НЕ трогай секреты, креды, токены.

## Git
- Коммить инкрементально. В конце — ЧИСТОЕ дерево. 0 коммитов = провал.
- Формат: `#NNNNN type(scope): описание` (Conventional, по-русски). НЕ squash.
- Ветка уже создана (имя = `#NNNNN`).

## Scope
- Только в рамках задачи и её paths. Не рефакторить соседнее.
- scopeMode:"files": изолированная копия — видишь только paths. Не достраивай.

## Анти-галлюцинация
- Только то, что в ТЗ + подтверждено кодом. Имена после «например» — иллюстрация.
- Недоопределено → честный `// TODO`. Следуй конвенциям репо.

## Экономия контекста
- Греп: сначала count/files_with_matches, потом head_limit. Никаких широких вайлдкардов.
- Чтение: сначала `wc -l`, большие файлы диапазонами.
- Язык: проза по-русски, код по-английски. Задача невыполнима → скажи честно.
